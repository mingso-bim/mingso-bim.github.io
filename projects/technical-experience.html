C++에서 파티클 데이터와 렌더링 리소스 구성

CreateParticles(5000)로 파티클마다 위치, 값, 색상, 시작 시간, 속도, 수명, 질량, 주기, UV를 정점 데이터로 구성해 VBO에 저장하고, Vertex Attribute로 셰이더에 전달했습니다.

CreateFBOs()에서는 GL_RGBA16F 렌더 타깃 두 개를 GL_COLOR_ATTACHMENT0, GL_COLOR_ATTACHMENT1에 연결한 HDR Framebuffer와, Blur에 사용할 Ping-Pong FBO·Texture 2개를 구성하고 각 Framebuffer의 상태를 검사했습니다.

02

Vertex Shader에서 시간과 중력을 이용한 이동 계산

Particle.vs에는 fountain, sinParticle, circleParticle, waterParticle 함수가 있으며, 실행 결과에 사용한 main()은 circleParticle()만 호출합니다. circleParticle()은 a_Value로 원 위의 시작 위치를 정하고, 시작 시간 이후 수명 주기로 반복되는 시간 t에 중력 가속도를 적용해 위치를 계산합니다. 수명이 지날수록 알파가 감소합니다.

초기 속도와 외력(u_Force)을 사용하는 계산은 fountain()에 구현되어 있으며, 실행 결과에는 사용하지 않았습니다.

코드 보기

실제 코드 일부 발췌 · Particle.vs — circleParticle() 본문 

vec4 newPosition = vec4(a_Position, 1);
// ...
float newAlpha = 1;
float lifeTime = a_LifeTime;
float newTime = u_Time - a_sTime;

if (newTime > 0)
{
    float value = a_Value * c_PI * 2;
    float x = sin(value);
    float y = cos(value);
    float t = fract(newTime/lifeTime) * lifeTime;
    float tt = t*t;
    float newX = x + 0.5 * c_G.x * tt;
    float newY = y + 0.5 * c_G.y * tt;
    newPosition.xy += vec2(newX, newY);
    newAlpha = 1-t/lifeTime;
}
// ...
v_Color = vec4(a_Color.rgb*3*newAlpha, newAlpha);

실제 코드 일부 발췌 · Texture.fs — BlurH() 

const float weight[5] = float[] (0.227027, 0.1945946, 0.1216216, 0.054054, 0.016216);
// ...
vec4 BlurH()
{
    vec2 tex_offset = 1.0 / textureSize(u_TexID, 0); // gets size of single texel
    vec3 result = texture(u_TexID, v_Tex).rgb * weight[0]; // current fragment's contribution

    for(int i = 1; i < 5; ++i)
    {
        result += texture(u_TexID, v_Tex + vec2(tex_offset.x * i, 0.0)).rgb * weight[i];
        result += texture(u_TexID, v_Tex - vec2(tex_offset.x * i, 0.0)).rgb * weight[i];
    }

    return vec4(result, 1.0);
}
05

원본 장면과 Blur 결과 합성

원본 HDR Texture에 Blur 결과를 더한 뒤 Tone Mapping과 Gamma Correction을 적용해 최종 화면을 출력했습니다.

코드 보기

실제 코드 일부 발췌 · Texture.fs — Merge() 

vec4 Merge()
{
    const float gamma = 2.2;
    vec3 hdrColor = texture(u_TexID, vec2(v_Tex.x, 1-v_Tex.y)).rgb;
    vec3 bloomColor = texture(u_TexID1, v_Tex).rgb;
    hdrColor += bloomColor;

    // tone mapping
    vec3 result = vec3(1.0) - exp(-hdrColor * 2.2);

    // also gamma correct while we're at it
    result = pow(result, vec3(1.0 / gamma));
    return vec4(result, 1.0);
}
